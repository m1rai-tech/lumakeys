# Luma Keys

A browser-based piano with sampled Steinway B and Yamaha C5 sounds and a 2D neon visualizer.

- Play with a computer keyboard, mouse, touch, or MIDI controller.
- Import MIDI files, play them in the background, or step through them one note or chord at a time.
- Customize the sound, sustain, key labels, and lighting.
